## 1. 项目定位

心灵特调（Resonant Sips）是一个赛博朋克酒吧题材的 AI 叙事调酒原型。玩家通过对话观察顾客、判断其隐藏情绪，再用一杯酒作为非语言回应。当前核心闭环是：

```text
选择并加载角色
  → 对话与信任变化
  → 选择 3 个真实情绪
  → 生成三维调酒目标或态度方向
  → 选择杯型、冰块、原液和装饰
  → 递酒判定与顾客反馈
  → 写入本地存档并推进顾客/天数
```

## 2. 当前技术基线

- 前端：React 18 + Vite 5。
- 图形依赖：PixiJS 8。
- 当前主要 UI：React/DOM/CSS。
- 服务端：Node.js HTTP 服务，入口为 `server/save-server.mjs`。
- 持久化：浏览器本地存储 + `saves/` 文件型存档。
- 角色数据：统一使用本地 `character.json` 清单与独立角色资产目录；无外部角色源回退。
- AI：Gemini、DeepSeek，以及通过兼容端点接入的模型服务。
- 语音：浏览器语音与可选远程 TTS。
- 生图：模型生图 API，由服务端统一调用并缓存角色资产。

### 3.3 八维情绪与玩家判断

- 使用 joy、trust、fear、surprise、sadness、disgust、anger、anticipation 八个情绪 ID。
- 情绪分析输出包含权重、Top3、confidence、rationale、source 和 sourceHash。
- 系统会清理非法 ID、补齐缺失值、限制范围、归一化并重新计算 Top3。
- 模型不可用或解析失败时存在 heuristic 回退。
- 玩家选择 3 个情绪后进入调酒。
- strict/transitional 模式下，已使用 3 个所选情绪的组合向量生成可解三维目标。
- 命中真实 Top3 和表面情绪会影响奖励与信任。

### 3.4 调酒与结算

- 当前调酒步骤为：杯型 → 冰块 → 原液 → 装饰 → 递酒。
- garnish 字段仍为兼容数据，但已不作为独立操作步骤。
- 主要数值维度为 thickness、sweetness、strength。
- 支持 strict、transitional、expressive、master 四种判定模式的代码路径。
- 已有确定性数值判定、容差判定、鸡尾酒态度、失调检测与有限 AI 共鸣判断。
- 同一配方可以产生数值结果、共鸣等级、信任和收益变化。

注意：主线章节推进当前关闭，因此正常流程通常不会自动经历全部调酒模式。完整模式推进方式仍需产品决策。
